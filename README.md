## Технически

- `vite.config.js` — `vite-plugin-pwa` сам генерирует manifest и service worker
- `src/lib/storageShim.js` — подменяет `window.storage` на localStorage, вся offline-очередь `useShiftsStore` работает как в артефакте
- Иконки в `public/` — растеризованы из `WatermelonMark`, теми же цветами
- `src/index.css` — CSS для всех `.wm-*` классов написан с нуля (в присланном файле стилей не было вообще)
- Синтаксис `App.jsx`/`index.css` проверен через esbuild — собирается без ошибок. Установить зависимости и прогнать реальный `vite build` в этой среде нельзя (нет сети), поэтому финальная сборка — на твоей стороне, шаги ниже.

## Путь без установки чего-либо на телефоне (проще всего)

1. Заходишь на github.com → New repository → любое имя (например `watermelon-pwa`)
2. "uploading an existing file" → перетаскиваешь всю папку проекта
3. Идёшь на vercel.com → Add New → Project → выбираешь этот репозиторий → Deploy
   (Vercel сам увидит Vite-проект, поставит зависимости и соберёт — ничего настраивать не нужно)
4. Через минуту получаешь ссылку вида `watermelon-pwa.vercel.app`
5. Открываешь эту ссылку на телефоне → браузер предложит "Добавить на экран" / "Установить приложение"

Дальше при каждом обновлении файлов в GitHub-репозитории Vercel пересобирает сайт сам.

## Локально, если есть Node.js на компьютере

```
npm install
npm run dev        # разработка, localhost
npm run build       # финальная сборка в папку dist/
npm run preview     # проверить собранную версию
```

## Что стоит проверить при первом запуске

- Открой смену → введи продажу больше остатка партии → должна появиться ошибка "в остатке только N", продажа не добавится
- Закрой смену → зайди в "Смотреть прошлые смены" → закрытая смена должна появиться в списке со средним темпом
- Пополни партию → остаток на главном экране должен вырасти на добавленное количество
